### 問題 1
2けたの5進数の中でいちばん小さい数は何ですか。その数を5進数と10進数で答えてください。

<details>
<summary>解答と解説を見る</summary>

#### 【解答】
* **5進数:** $10_{(5)}$
* **10進数:** $5$

#### 【解説】
2けたの数で最も小さい数は、上の位（左の位）が「1」、下の位（右の位）が「0」となります。したがって、5進数では $10_{(5)}$ です。これを10進数に直すと、1 * 5 + 0 = 5 となります。

</details>

### 問題 7
すべての2けたの5進数を画面に表示するPythonのプログラムを作ってください。

<details>
<summary>解答と解説を見る</summary>

#### 【解答】
```python
for left in range(1, 5):
    for right in range(0, 5):
        print(f"{left}{right}")
```

#### 【解説】
* 左の位 (`left`) は `1, 2, 3, 4` を取るため `range(1, 5)`
* 右の位 (`right`) は `0, 1, 2, 3, 4` を取るため `range(0, 5)`
* 二重ループで組み合わせることで、10, 11, 12, ... , 44 までのすべての2けたの5進数が表示されます。

</details>

### 問題 10
ある2けたの5進数があります。  
その数の左の位の数と右の位の数を入れ替えます。  
例 34 -> 43  
入れ替えた数を7進数だと考えて値を計算します。  
例  
34(5進数) = 3 * 5 + 4 = 15 + 4 = 19  
43(7進数) = 4 * 7 + 3 = 28 + 3 = 31  
この2つの数が等しくなる場合を答えてください。

<details>
<summary>解答と解説を見る</summary>

#### 【解答】
$32_{(5)}$ （10進数で表すと **17**）

#### 【解法1：数学的な解き方】
元の2けたの5進数を $ab_{(5)}$ とおきます。
* $a$ （左の位）：1, 2, 3, 4 のいずれか
* $b$ （右の位）：0, 1, 2, 3, 4 のいずれか

1. **10進数の式に表す:**
   * 元の数 $ab_{(5)}$ の値：$5a + b$
   * 左右を入れ替えた数 $ba_{(7)}$ の値：$7b + a$

2. **2つの値が等しくなる方程式を立てる:**
   $$5a + b = 7b + a$$
   $$4a = 6b$$
   $$2a = 3b$$

3. **範囲を満たす $a, b$ を求める:**
   * $a$ は 1, 2, 3, 4 のいずれかです。
   * $2a = 3b$ より、$a$ は3の倍数でなければならないため、$a = 3$ と定まります。
   * $a = 3$ を代入すると $2 \times 3 = 3b$ となり、$b = 2$ と求まります。

4. **確かめ:**
   * 元の数：$32_{(5)} = 3 \times 5 + 2 = 17$
   * 入れ替えた数：$23_{(7)} = 2 \times 7 + 3 = 17$

どちらも値が「17」で等しくなるため、求める2けたの5進数は $32_{(5)}$ となります。

#### 【解法2：Pythonを使ったプログラムによる解き方（全探索）】

```python
# 2けたの5進数を全探索する
for a in range(1, 5):      # 左の位 (1, 2, 3, 4)
    for b in range(0, 5):  # 右の位 (0, 1, 2, 3, 4)
        
        # 元の数: ab(5進数) を10進数に変換
        val_base5 = a * 5 + b
        
        # 入れ替えた数: ba(7進数) を10進数に変換
        val_base7 = b * 7 + a
        
        # 2つの値が等しいかチェック
        if val_base5 == val_base7:
            print(f"元の5進数: {a}{b}(5)")
            print(f"入れ替えた7進数: {b}{a}(7)")
            print(f"10進数の値: {val_base5}")
```

**実行結果:**
```text
元の5進数: 32(5)
入れ替えた7進数: 23(7)
10進数の値: 17
```

</details>
